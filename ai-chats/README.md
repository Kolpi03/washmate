# AI chats

Put the **real, unedited exports** of the AI conversations you used for this project in this folder.

How to export:
- **Claude Code (terminal):** run `/export` inside the session and save the file here, or copy the transcript from
  `~/.claude/projects/<project>/*.jsonl`.
- **claude.ai / ChatGPT / other web chats:** use the app's *Export / Share → Download* option, or copy the full conversation into a `.md` file.

Name files like `2026-11-11-washmate-build.md`. Do not edit, trim or reconstruct conversations – evaluators expect the genuine record.
