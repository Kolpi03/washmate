# WashMate demo

**Video:** [`washmate-demo.mp4`](washmate-demo.mp4) – ~3 minutes, **silent** (H.264 video stream only; verified with `ffprobe` – no audio stream),
recorded by Playwright from the **real running application** (no mock-ups, no animation).

## Environment used
* Local instance started by `demo/serve-demo.sh`: Flask API (port 5055) + the production build of the React app (port 4173).
* Fresh **throw-away SQLite database** (`.tmp/demo.db`, git-ignored) created on every start.
* **Dedicated test accounts** (`demo.student@washmate.test`, `operator@washmate.test`) with demo-only passwords defined in
  `demo/serve-demo.sh` / `tests/e2e/demo.spec.js`. They exist only in that throw-away database; never reuse them anywhere else.
* **No real payments:** the UPI ID is the fake `demo.hostel@testupi` and the transaction references (`DEMOSETUP0001`, `DEMOTEST000001`) are made-up test strings.
* Demo-only operator settings (24-hour operating window, 5-minute slot grid) are applied through the operator API so a near-term slot always exists.
* The 15-minute reminder is generated by the app's own reminder logic: before recording, a test booking ~16 minutes in the future is created
  and the script waits until the scheduler really generates the reminder.

## What the video shows
1. Landing page → student login (typed with visible cursor) → dashboard (next appointment, stats, notifications)
2. Book a Wash: choose **Heavy Wash** (price, duration, estimated water) → date → available appointment → booking review
3. UPI payment page (amount, UPI ID, instructions) → submit test transaction reference → "waiting for verification"
4. My Bookings → booking details → Notifications showing the **15-minute appointment reminder** → logout
5. Operator login → overview → machines (set M3 to maintenance with a reason, then restore) → wash-mode configuration
6. Payments: verify the test transaction → Appointments (table, daily schedule, calendar) → rescheduling request approval
7. Reports (daily, weekly) with charts → CSV export → logout

Screenshots taken during the same run are in [`screenshots/`](screenshots/).

## Re-record
```bash
npm install && npx playwright install chromium
source .venv/bin/activate
bash demo/serve-demo.sh            # terminal 1 (restart it before every recording to reset the DB)
node tests/e2e/demo.spec.js        # terminal 2
```
Needs `ffmpeg`/`ffprobe`. The script fails loudly if the output contains an audio stream. Run it before 23:30 server time.
